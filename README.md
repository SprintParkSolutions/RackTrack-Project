# RackTrack — marketing site

Static HTML. No framework, no server required — open `index.html` in a browser.

## Build

The stylesheet is compiled, **not** generated in the browser.

```sh
./build.sh
```

Run this after **any** markup change. Tailwind scans the HTML and emits only
the classes it finds, so a class you just typed does not exist in
`racktrack.css` until the build runs — and nothing errors when it is missing,
the element just silently falls back to its inherited style.

## Layout

```
index.html                 home — the entry point
why-racktrack.html        \
solutions.html             |
use-cases.html             |  the seven top-level pages
trust-security.html        |
resources.html             |
about-us.html              |
contact-us.html           /

article-*.html            9 resource articles
use-case-*.html           6 use-case pages

racktrack.css             built stylesheet — every page links it
tailwind.config.js        design tokens: colour, spacing, type scale
tw-input.css              build input (the three @tailwind directives)
build.sh                  rebuild racktrack.css

assets/                   images the pages serve
docs/                     source copy and design notes
tools/                    drawing-sheet generators
media/                    raw inputs — not tracked, see .gitignore
```

All 23 pages sit at the root because their links are flat and relative
(`href="solutions.html"`), which is what makes the site work equally from the
filesystem and from any static host. Moving them into a subfolder would mean
rewriting every link and every asset path for no functional gain.

## Design system

`docs/DESIGN.md` has the full detail. In short:

**Type** — one nine-step ramp: 11, 13, 15, 18, 20, 26, 30, 38, 46. Headings
use named component classes (`.h1`, `.h2`, `.h2-sm`, `.h3`, `.h4`), never
per-element size overrides. Geist throughout; Geist Mono for labels, captions
and anything drawing-related.

**Colour** — navy shell (`--shell`), white and tinted-white grounds, muted
grey body text, one blue accent (`#1a3fd4`). Dark bands punctuate; they are
not the ground.

**Drawings** — the technical sheets are generated by the scripts in `tools/`
and inlined as SVG. White paper, `#1a1a1a` linework, `#6f6f6f` secondary,
`#b8b8b8` hatch, one blue. Regenerate a sheet by running its script and
re-injecting the output.

## Media

`media/` holds source photography, screen recordings and superseded assets.
It is deliberately untracked — it was adding about 35 MB to the repository.
Keep the originals there; put only the sized, compressed derivative the pages
actually load into `assets/`.
